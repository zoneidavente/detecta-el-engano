2. Caso de estudio: ataque de phishing por SMS

En agosto de 2022, Cloudflare publicó un análisis sobre un ataque de phishing mediante mensajes de texto dirigido a sus empleados. Los atacantes enviaron mensajes que imitaban comunicaciones de confianza y utilizaron páginas falsas para intentar obtener credenciales de acceso.

El caso muestra cómo los delincuentes pueden utilizar la ingeniería social para generar confianza y presionar a las personas para que ingresen información privada.

Aprendizaje del caso: no debemos confiar en un mensaje únicamente porque utiliza el nombre o la imagen de una institución conocida. Es necesario verificar la solicitud por un canal oficial.

Fuente: Cloudflare (2022). The mechanics of a sophisticated phishing scam and how we stopped it.

3. Conceptos de seguridad

Concepto 1. Phishing y smishing

El phishing es una técnica de ingeniería social en la que los delincuentes suplantan la identidad de entidades confiables para obtener información personal. Cuando el engaño se realiza mediante mensajes SMS, se conoce como smishing.

Concepto 2. Partes de una dirección URL

Una URL permite identificar una dirección en internet. Dos de sus partes importantes son:

Dominio: identifica el servidor o sitio al que se dirige la solicitud.

Ruta: indica el recurso o ubicación solicitada dentro del sitio.

Ejemplo: https://universidad.example/login

Dominio: universidad.example

Ruta: /login

Dos medidas de protección

  1. Revisar cuidadosamente el remitente y el dominio del enlace antes de abrirlo.
  2. Confirmar cualquier solicitud de actualización de datos comunicándose directamente con los canales oficiales de la institución.

4. Evidencia del laboratorio

Se realizó una prueba local en Python utilizando la biblioteca urllib.parse para analizar dos direcciones URL ficticias y comparar sus dominios y rutas.

Condiciones de prueba

URL A: https://soporte-universidad.example/login

URL B: https://soporte-universidad.example/actualizar-cuenta

Resultado obtenido

===== ANALISIS DE URL =====

CONDICION A: URL ORIGINAL
URL: https://soporte-universidad.example/login
Dominio: soporte-universidad.example
Ruta: /login

CONDICION B: URL MODIFICADA
URL: https://soporte-universidad.example/actualizar-cuenta
Dominio: soporte-universidad.example
Ruta: /actualizar-cuenta

===== COMPARACION =====

Ambas URL tienen el mismo dominio.
Las rutas son diferentes.
Interpretación: el resultado confirmó que las dos direcciones tienen el mismo dominio, pero solicitan rutas diferentes. Por tanto, modificar la ruta no significa necesariamente cambiar el dominio.
Alcance de la prueba: se utilizaron direcciones ficticias terminadas en .example. El laboratorio analizó su estructura sin conectarse a servidores. Este análisis no determina si una página es legítima o maliciosa.

¿Qué aprendimos?

Aprendimos a identificar las partes de una URL y comprendimos la importancia de revisar cuidadosamente los enlaces antes de ingresar información personal.

6. Acción final: protege tu información

Antes de abrir un enlace recibido por mensaje o correo, detente y realiza estas acciones:

  1. Revisa quién envió el mensaje.
  2. Comprueba el dominio de la dirección URL.
  3. Verifica la solicitud mediante un canal oficial.
  4. Nunca compartas contraseñas ni códigos de verificación.
Tu decisión importa: ante un mensaje sospechoso, no hagas clic por impulso. Verifica primero y protege tus datos.
